# The ADR counter. One line per number allocated, lowest first, `<id> <slug>`.
#
# `aurora-tools adr new "<title>"` appends the next line and writes the file. Two branches allocating
# at once collide on the same line — which is the point. A merge conflict is a one-line fix; two
# accepted decisions sharing a number is not.
#
# A line with no file beside it is a **reservation**: the number is spoken for by a plan that has not
# been written up yet. `check-adr` counts written against reserved, which is how exit criterion 15
# ("all nineteen ADRs are accepted") becomes a number rather than a claim.
